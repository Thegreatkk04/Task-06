## Objective
Analyze monthly revenue and order volume using SQL aggregation functions.

- SQL

## Dataset
E-commerce Sales Dataset

Tables:
1. Orders
2. Details

## SQL Concepts Used

- GROUP BY
- SUM()

## Analysis Performed

### Monthly Revenue Analysis
Calculated total revenue generated each month.

### Monthly Order Volume
Calculated unique orders placed each month.

### Top 3 Months by Revenue
Identified the highest performing sales months.

### Monthly Profit Analysis
Tracked monthly profit trends.

### Category Analysis
Compared revenue across product categories.
